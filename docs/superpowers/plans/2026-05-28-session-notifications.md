# Session Start/End Notifications Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fire Filament database (bell) notifications to admins (super-admin + moderator) whenever a WebRTC publish or read session starts or ends, with cache-backed dedupe for read events and a flood cap.

**Architecture:** A new scheduled console command runs every 10 seconds. It calls `MediamtxSessionRefresher::refresh()` which now returns a `SessionDiff` (started/ended events) computed by diffing the MediaMTX API response against the `mediamtx_sessions` table before upserting. The diff is handed to a new `SessionNotifier` service that applies dedupe (5-minute window for read events, keyed by IP+path) and a per-minute flood cap (20 read.started/min), then writes one `database_notifications` row per recipient via Filament's notification API.

**Tech Stack:** Laravel 12, PHP 8.2+, Filament v3, Spatie Permissions, PHPUnit 11, SQLite-in-memory tests, `array` cache driver in tests.

**Spec reference:** [`docs/superpowers/specs/2026-05-28-session-notifications-design.md`](../specs/2026-05-28-session-notifications-design.md)

<?php

namespace App\Services;

use App\Models\MediamtxSession;

class MediamtxSessionRefresher
{
    public function __construct(private readonly MediamtxApi $api) {}

    public function refresh(): SessionDiff
    {
        $now = now();

        $items = data_get($this->api->listWebRtcSessions(), 'items', []);

        $rows = collect($items)->map(function ($it) {
            $remote = (string) data_get($it, 'remoteAddr', '');

            return [
                'type' => 'webrtc',
                'session_id' => (string) data_get($it, 'id', ''),
                'state' => (string) data_get($it, 'state', ''),
                'path' => (string) data_get($it, 'path', ''),
                'query' => (string) data_get($it, 'query', ''),
                'remote_addr' => $remote,
                'ip' => $this->extractIp($remote),
                'created' => (string) data_get($it, 'created', ''),
                'bytes_received' => (int) data_get($it, 'bytesReceived', 0),
                'bytes_sent' => (int) data_get($it, 'bytesSent', 0),
            ];
        })->filter(fn ($r) => $r['session_id'] !== '')->values();

        $apiIds = $rows->pluck('session_id')->all();

        // Existing rows BEFORE upsert, used for diff. Only the webrtc type matters here.
        $existing = MediamtxSession::query()
            ->where('type', 'webrtc')
            ->get(['session_id', 'state', 'path', 'ip', 'created', 'last_seen_at'])
            ->keyBy('session_id');

        $started = [];
        foreach ($rows as $row) {
            if (! $existing->has($row['session_id'])) {
                $kind = $this->stateToKind($row['state']);
                if ($kind === null) {
                    continue;
                }
                $started[] = new SessionEvent(
                    kind: $kind,
                    sessionId: $row['session_id'],
                    path: $row['path'],
                    ip: $row['ip'],
                    state: $row['state'],
                    occurredAt: $row['created'] !== '' ? $row['created'] : $now->toIso8601String(),
                );
            }
        }

        $ended = [];
        foreach ($existing as $sessionId => $old) {
            if (! in_array($sessionId, $apiIds, true)) {
                $kind = $this->stateToKind((string) $old->state);
                if ($kind === null) {
                    continue;
                }
                $ended[] = new SessionEvent(
                    kind: $kind,
                    sessionId: $sessionId,
                    path: (string) $old->path,
                    ip: (string) $old->ip,
                    state: (string) $old->state,
                    occurredAt: optional($old->last_seen_at)->toIso8601String() ?? $now->toIso8601String(),
                );
            }
        }

        foreach ($rows as $row) {
            MediamtxSession::updateOrCreate(
                ['type' => $row['type'], 'session_id' => $row['session_id']],
                $row + ['last_seen_at' => $now],
            );
        }

        $stale = (int) config('services.mediamtx.stale_seconds', 20);
        MediamtxSession::where('last_seen_at', '<', now()->subSeconds($stale))->delete();

        return new SessionDiff(started: $started, ended: $ended);
    }

    private function stateToKind(string $state): ?string
    {
        return match ($state) {
            'publish' => 'publish',
            'read' => 'read',
            default => null,
        };
    }

    private function extractIp(string $remoteAddr): string
    {
        if (str_starts_with($remoteAddr, '[')) {
            $end = strpos($remoteAddr, ']');

            return $end !== false ? substr($remoteAddr, 1, $end - 1) : $remoteAddr;
        }

        if (substr_count($remoteAddr, ':') === 1) {
            return explode(':', $remoteAddr, 2)[0];
        }

        return $remoteAddr;
    }
}

<?php

namespace App\Services;

use App\Models\User;
use Filament\Notifications\Notification;

class SessionNotifier
{
    public function dispatch(SessionDiff $diff): void
    {
        $recipients = $this->recipients();
        if ($recipients->isEmpty()) {
            return;
        }

        foreach ($diff->started as $event) {
            $this->sendForEvent($event, 'started', $recipients);
        }

        foreach ($diff->ended as $event) {
            $this->sendForEvent($event, 'ended', $recipients);
        }
    }

    private function sendForEvent(SessionEvent $event, string $phase, \Illuminate\Support\Collection $recipients): void
    {
        $titleVerb = match ([$event->kind, $phase]) {
            ['publish', 'started'] => 'New publisher on',
            ['publish', 'ended'] => 'Publisher ended on',
            ['read', 'started'] => 'New viewer on',
            ['read', 'ended'] => 'Viewer ended on',
            default => null,
        };

        if ($titleVerb === null) {
            return;
        }

        $color = $phase === 'started' ? 'success' : 'gray';

        Notification::make()
            ->title("{$titleVerb} {$event->path}")
            ->body("IP {$event->ip}")
            ->icon('heroicon-o-signal')
            ->color($color)
            ->sendToDatabase($recipients);
    }

    private function recipients(): \Illuminate\Support\Collection
    {
        return User::role(['super-admin', 'moderator'])->get();
    }
}

<?php

namespace App\Services;

use App\Filament\Pages\Sessions;
use App\Models\User;
use Filament\Notifications\Actions\Action;
use Filament\Notifications\Notification;
use Illuminate\Support\Collection;
use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Facades\Log;

class SessionNotifier
{
    private const READ_DEDUPE_TTL_SECONDS = 300;
    private const READ_FLOOD_CAP_PER_MINUTE = 20;

    public function dispatch(SessionDiff $diff): void
    {
        $recipients = $this->recipients();
        if ($recipients->isEmpty()) {
            return;
        }

        foreach ($diff->started as $event) {
            $this->maybeSend($event, 'started', $recipients);
        }

        foreach ($diff->ended as $event) {
            $this->maybeSend($event, 'ended', $recipients);
        }
    }

    private function maybeSend(SessionEvent $event, string $phase, Collection $recipients): void
    {
        $titleVerb = match ([$event->kind, $phase]) {
            ['publish', 'started'] => 'New publisher on',
            ['publish', 'ended'] => 'Publisher ended on',
            ['read', 'started'] => 'New viewer on',
            ['read', 'ended'] => 'Viewer ended on',
            default => null,
        };

        if ($titleVerb === null) {
            return;
        }

        if (! $this->passesDedupe($event, $phase)) {
            return;
        }

        if ($event->kind === 'read' && $phase === 'started' && ! $this->passesReadFloodCap()) {
            return;
        }

        $color = $phase === 'started' ? 'success' : 'gray';

        Notification::make()
            ->title("{$titleVerb} {$event->path}")
            ->body("IP {$event->ip}")
            ->icon('heroicon-o-signal')
            ->color($color)
            ->actions([
                Action::make('view_sessions')
                    ->label('View sessions')
                    ->url(Sessions::getUrl(), shouldOpenInNewTab: false)
                    ->markAsRead(),
            ])
            ->sendToDatabase($recipients);
    }

    private function passesDedupe(SessionEvent $event, string $phase): bool
    {
        $key = match ([$event->kind, $phase]) {
            ['publish', 'started'] => "notify:publish.started:{$event->sessionId}",
            ['publish', 'ended'] => "notify:publish.ended:{$event->sessionId}",
            ['read', 'started'] => "notify:read.started:{$event->ip}:{$event->path}",
            ['read', 'ended'] => "notify:read.ended:{$event->ip}:{$event->path}",
            default => null,
        };

        if ($key === null) {
            return false;
        }

        $ttl = match ($event->kind) {
            'read' => self::READ_DEDUPE_TTL_SECONDS,
            'publish' => 3600, // publish events are session-unique; 1h is enough to prevent any double-tick from rapid retries
            default => 60,
        };

        return Cache::add($key, 1, $ttl);
    }

    private function passesReadFloodCap(): bool
    {
        $minuteKey = 'notify:read:flood:'.now()->format('YmdHi');
        $count = Cache::increment($minuteKey);
        if ($count === 1) {
            // increment created the key; give it a 65s TTL so it expires after the minute.
            Cache::put($minuteKey, 1, 65);
        }

        if ($count > self::READ_FLOOD_CAP_PER_MINUTE) {
            $logGate = 'notify:read:flood:logged:'.now()->format('YmdHi');
            if (Cache::add($logGate, 1, 65)) {
                Log::warning('Read-session notification flood cap reached', [
                    'minute' => now()->format('YmdHi'),
                    'cap' => self::READ_FLOOD_CAP_PER_MINUTE,
                ]);
            }

            return false;
        }

        return true;
    }

    private function recipients(): Collection
    {
        return Cache::remember(
            'notify:recipients:admins',
            60,
            fn () => User::role(['super-admin', 'moderator'])->get(),
        );
    }
}

## Notes for the implementer

- The `array` cache driver in tests means the dedupe/flood-cap state is per-test and resets between tests via `RefreshDatabase`. No extra teardown needed.
- All notifier tests rely on `RolesSeeder` being run in `setUp()` — without it `User::role(...)` fails because the role doesn't exist.
- `User::factory()` already exists. Newly created users have no roles until `assignRole(...)` is called.
- We never modify the existing `MediamtxSession` schema; the diff is computed in memory by comparing IDs before the upsert/delete cycle.
- The `created` column on `mediamtx_sessions` is a string in the API payload — keep it that way; tests pass ISO strings.
- Pint formatting is part of the project workflow but not strictly required for tests to pass.
